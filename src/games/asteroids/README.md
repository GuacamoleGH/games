# Asteroids — GuacamoleGH Games

Módulo aislado e independiente de Asteroids para GuacamoleGH Games.

- **Engine:** `AsteroidsEngine.ts` con cinemática inercial 2D, envolvente toroidal, proyectiles y división de asteroides en 3 escalas.
- **View:** `AsteroidsView.ts` en Canvas HTML5 con gráficos vectoriales retro-neón, soporte táctil móvil y controles por teclado.
- **Trazabilidad:** `@spec REQ-53, REQ-54, REQ-55, REQ-56`.
