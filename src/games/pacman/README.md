# Pac-Man — GuacamoleGH Games

Módulo aislado e independiente de Pac-Man para GuacamoleGH Games.

- **Engine:** `PacmanEngine.ts` con laberinto de 19x21, pellets, energizers y 4 fantasmas con IA (Blinky, Pinky, Inky, Clyde).
- **View:** `PacmanView.ts` en Canvas HTML5 con animación retro-neón, soporte táctil móvil y atajos por teclado.
- **Trazabilidad:** `@spec REQ-49, REQ-50, REQ-51, REQ-52`.
