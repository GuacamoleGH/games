# Blackjack — GuacamoleGH Games

Módulo aislado e independiente de Blackjack para GuacamoleGH Games.

- **Engine:** `BlackjackEngine.ts` con baraja de 52 cartas, cómputo óptimo de Ases (1 u 11), acciones Pedir / Plantarse / Doblar, y reglas de la casa para el crupier (planta en 17+).
- **View:** `BlackjackView.ts` con diseño de tapete de paño de casino, naipes vectoriales SVG de alta definición, controles accesibles en formato rectangular unificado y atajos por teclado.
- **Créditos de Naipes:** Baraja de cartas SVG extraída de [cardsJS](https://github.com/richardschneider/cardsJS/tree/master) creada por Richard Schneider.
- **Trazabilidad:** `@spec REQ-57, REQ-58, REQ-59, REQ-60`.
